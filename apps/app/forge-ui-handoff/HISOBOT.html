1 · Asboblar (F1–F7 + F03)

Har biri: nima qiladi · qanday qilingan (texnik) · Moblo 1:1 · qonun. Rang-kod: X eni Y bo'y Z qalinlik.

F1

MOVE — ko'chirish

1:1 (yadro)

Nima qiladi

Panelni sudrab ko'chirish. Sudrash paytida yashil punktir vino​ska + yashil jonli pill (cm). Tik (Y) sudraganda raqam = yergacha balandlik (Moblo uslubi, vino​ska polga tushadi); yotiq (X/Z) = siljish.

Qanday qilingan

TransformControls translate gizmosi ustiga qurilgan. Qo'yib yuborgach yashil ✎ resting-chip qoladi → bosilsa Numpad (cm, expr-eval matematika) → aniq pozitsiya → onDragPanel. Pol = y=0; ixtiyoriy groundY_mm10 prop (host boshqa pol bersa).

Moblo 1:1

Yadro mos — yashil leader + balandlik + chip. Kechiktirilgan: «Put on ground» tugmasi + «Measure» ruletka (Moblo'da bor, biz keyinga qoldirdik). Markaz-4-tomon planar ham hozircha bitta o'q.

Qonun

Faqat Stage3D.tsx; contract tegilmadi; balandlik-need README oxirida.

F2

RESIZE — o'lcham

1:1

Nima qiladi

Panel yuzidagi puckni ushlab-sudrab o'lchamni o'zgartirish. qizil = eni yashil = bo'y. Sudralganda qizil/yashil size-chip (o'q rangida) + qizil leader; qarama-qarshi yuz qotiriladi.

Qanday qilingan

Handle'lar host'dan (SideHandle[], axis bilan). D fazasida Moblo'ga keltirildi: to'q sariq kub → yassi o'q-rangli puck (normal o'qida yupqa Box, x=qizil/y=yashil); to'g'ri grab+drag (2-qadam olib tashlandi); size-chip o'q-rangli (axisX/Y/Z tone). Qo'yib yuborgach ✎ → Numpad «Размер, см» → onDragHandle. Faqat eni(X)+bo'y(Y) — chuqurlik(Z)=profil, puck yo'q.

Uniform / link

Pastki-chapda 🔗 zanjir tugmasi (yoqilsa ko'k). Yoqiq bo'lsa enini sudrasangiz bo'y ham proporsional o'zgaradi (nisbat saqlanadi) — mavjud onDragHandle orqali ikkinchi o'qqa emit. Qalinlik hech qachon — profil.

Moblo 1:1

1:1 bo'ldi (D). Grounded farq: Moblo 3 o'qni ham proporsional qiladi, biz faqat 2-o'q (qalinlik = profil qonuni).

Qonun

Stage3D + measure.ts (axis-tone) + styles.css; contract tegilmadi; onDragHandle mavjud mexanizm.

F3

ROTATE — burish

1:1

Nima qiladi

3 ta rang-halqa X Y Z bilan burish. Halqa sudralganda swept pona (o'tilgan burchak) + o'q-rangli burchak-chip.

Qanday qilingan

TransformControls'ning 3 halqasi. Pona = CircleGeometry sektor (har freym qayta quriladi). A fazasida erkin qilindi: 90°-snap ikki joydan (numpad + release) olindi; endi istagan burchak, faqat 90° yaqinida ±4° yumshoq-snap. Numpad = aniq yozilgan son. D: burchak-chip axisX/Y/Z tone.

Moblo 1:1

1:1 bo'ldi (A) — Moblo ham erkin buradi (85°, −60°, −115°). Contract'da rx/ry/rz erkin radian bor edi. Pona — bizning qo'shimcha ko'rgazma.

Qonun

Contract'dagi rx/ry/rz ishlatildi (yangi maydon yo'q); mm10/burchak measure.ts.

F4

TARGET — nishon pinlar

1:1

Nima qiladi

⬡⊕ pinlar — modifikatorni (F03/F5/F6/F7) qayerga qo'yishni tanlash. «Модификатор» rejimi kirishi. Har burchak o'z yo'nalgan qavs-ikonkasi bilan (⌜⌝⌞⌟).

Qanday qilingan

panelCorners(p) — asosiy yuzning 4 burchagi (orientation.xAxis×yAxis; 3-o'q=qalinlik; qalinlik o'rtasida; rx/ry/rz aylantirilgan). Pinlar DOM tugma sifatida proyeksiya. Kichik panelda tiqilishni kamaytirish uchun sub-toggle «⌜Углы ⌐Кромки ⊔Вырез ▢Окно» — bir vaqtda faqat bitta oila.

Moblo 1:1

Sistema mos — pin → modifikator-muharrir kirishi.

Qonun

Yuz determinatsiyasi orientation'dan (grounded); contract tegilmadi.

F03

ROUND — burchak yumaloqlash

1:1

Nima qiladi

Burchakni yumaloqlash. Pin bosilsa muharrir: oq radius-chip + kulrang yoy-guide (2 qirraga tegib) + link (4 burchak bog'lash) + ✓/✕. Yumaloqlangan burchak yashil «⌒ radius» holat-pini bilan turadi.

Qanday qilingan

cornerArc() — chorak-doira yoy (qalinlik o'rtasi, aylantirilgan). Radius: Numpad (cm) YOKI drag-tutqich. Geometriya = MODEL: onApplyRound(cornerIds, radius) emit, UI faqat yoy chizadi + saqlaydi (appliedRounds). Reselect'da yashil pin qaytadi.

Moblo 1:1

Mos — Moblo'da ham burchak tanlanadi → radius chip + yoy; yumaloqlangan burchak holat ko'rsatadi.

Qonun

Contract'da round maydoni yo'q → model-side (README'da); UI faqat spec+guide.

F5

CHAMFER — qirra ishlovi

1:1

Nima qiladi

Qirraga fasska/rabbet (L-profil). Edge-pin → muharrir: en (qizil) + chuqurlik (kulrang) + link; qirra bo'ylab kulrang rabbet-tasma guide.

Qanday qilingan

panelEdges(p) — 4 qirra-o'rtasi + bo'ylab/ichkariga yo'nalish + uzunlik. onApplyChamfer(edgeIds, w, d); saqlanadi → edge-pin yashil. Model kesadi. Kichik panel uchun sub-toggle «Углы|Кромки».

Moblo 1:1

Mos — L-step-only hozircha (profil-tanlagich keyin).

Qonun

Model-side (README); contract tegilmadi.

F6

NOTCH — qirradagi vırez

1:1

Nima qiladi

Qirradagi U-o'yiq. Qizil sudraladigan 3D tutqichlar ◀▶ (en) · ▲ (chuqurlik) · ↔ (pozitsiya, ko'k). Kulrang qulflanadigan offset chiplar (qirra-uchlarigacha) + oq radius. Burchaklar radiusga qarab yumaloqlanadi. ✓/Удалить.

Qanday qilingan

Faza A: qizil U-guide + muharrir. Faza B: tutqichlarni ekran-fazo drag bilan sudrash (3D nuqta proyeksiya → ekran birlik-dir → px-per-mm10; delta'ni dir'ga skalyar) — har qanday qirra-orientatsiyada. Offset qulflansa o'sha tomon sudralmaydi. Saqlash onApplyNotch(...,lockL,lockR) — qulf ham saqlanadi (qayta ochganda turadi).

Moblo 1:1

1:1 — Moblo F6-01/03: qizil tutqichlar + kulrang qulf-offset + oq radius + yumaloq burchak. Aynan.

Qonun

Model-side (README'da to'liq spec); contract tegilmadi; qulflar UI-prop (contract emas).

F7

WINDOW — yuz o'rtasidagi oyna

1:1

Nima qiladi

Yuz ichida to'rtburchak teshik. Fazoviy chiplar (Moblo 1:1): 4 kulrang qulflanadigan offset qirralarga joylashgan + qizil eni/bo'y + oq radius + yashil ✓ + qizil ✕. 5 tutqich: ◀▶ (eni) ▲▼ (bo'y) ✥ (butun oynani surish).

Qanday qilingan

panelFace(p) — parametrik yuz-ramka (origin+ua+ub+w+h, aylantirilgan); world(u,v). Markaz-pin ⊞ → markazlashgan oyna. Faza A: qizil yumaloq-to'rtburchak guide + fazoviy chiplar + qulf-saqlash. Faza B: 5 tutqich — 2×2 ekran-bazo yechim (delta → yuz-tekislik du/dv), tomon resize + markaz 2D surish, qulf-hisobli.

Test panel

Harness'ga P3 (katta old-yuzli) qo'shildi — P1 (edge-on) va P2 (juda kichik) oyna uchun noqulay edi; P3 toza frontal (faqat test, yetkazilmaydi).

Moblo 1:1

Fazoviy 1:1 — Moblo F7-01: offsetlar qirrada, qizil size, oq radius, ✓, tutqichlar. Aynan. Hozircha bitta oyna/yuz (MVP).

Qonun

Contract Hole=parmalash (tekshirildi) — oyna F6 kabi model-side; README'da spec.
